# Reserve a book that is on loan

## Description
As a library member, I want to reserve a book that is currently on loan, so that I get it next when it is returned.

## Acceptance criteria
1. A book that is on loan shows a Reserve button on its catalogue page.
2. Pressing Reserve adds the member to the end of that book's reservation queue.
3. A member can't reserve a book they already have on loan.

## Dependencies
None.

## Open questions
None.
