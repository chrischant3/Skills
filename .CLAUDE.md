# Project Instructions

## Problem Statement
This project builds **Testzilla**, a code review Claude Code plugin that assesses complexity, reviews the tests' code, analyses a diff or PR, uncovers code that could be affected by the code changes, and assesses the test coverage of any impacted code.

## Primary Users
Software engineers and software testers.

## Success Criteria
The skill produces a report on its findings, suggests how to resolve them, and offers to resolve them.

## Technology Stack
The plugin is language and framework agnostic.

It includes these agents:
- **Test Reviewer:** reviews the tests in a diff, PR, or repo, and reports anything that doesn't follow good test automation standards.
- **Mutation Tester:** runs mutation tests on a diff, PR, or repo, and produces a report on the quality of each test it reviewed.

## Deployment Target
Published on the Claude Code plugin marketplace and as a public GitHub repository.

## Additional Context
Follow the patterns and rules in https://github.com/addyosmani/agent-skills/. The agent-skills plugin is being used to develop this plugin, and this project should be easy to understand for anyone who uses agent-skills.
